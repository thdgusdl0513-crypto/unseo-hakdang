내 캐릭터 저장
닉네임과 캐릭터는 이 기기에 저장돼서 다음부터 바로 들어와요. 다른 폰이나 브라우저에서는 같은 닉네임을 적으면 예전 캐릭터를 불러와요.

걷기 — 가고 싶은 바닥을 톡 누르면 걸어가요. 건물 문 앞을 누르면 안으로 들어가고, 실내에서는 아래쪽 금빛 발판을 눌러 나가요. 설정의 학당 지도로 바로 이동할 수도 있어요.

앉기와 타이머 — 빈 의자·방석·매트를 누르면 걸어가 앉아요. 강의실과 도서관에서는 공부·독서 타이머가 열려요(자유 / 25분 / 50분). 1분 이상부터 기록장에 남아요.

함께 읽기 — 타이머를 켠 친구 머리 위에 📖 몇 분째인지 보여요. 기록장의 ‘함께 기록’에서 친구들 기록도 볼 수 있어요.

도서관 — 가운데 빛나는 책 앞에서 읽은 책과 독후감을 서가에 꽂아요.

기숙사 — 아래 대화창으로 지금 접속한 친구들과 실시간 대화를 해요(대화는 저장되지 않아요). 오래 남길 말은 게시판 쪽지로.

닉네임·캐릭터 — 처음 정한 닉네임은 다음에 와도 그대로예요. 설정에서 언제든 바꿀 수 있어요.

앱처럼 아이콘을 눌러 바로 들어올 수 있어요.
  1. 삼성 인터넷: 아래쪽 ≡ 메뉴 → ‘현재 페이지 추가’ → ‘홈 화면’을 눌러요.
  2. 크롬: 오른쪽 위 ⋮ → ‘홈 화면에 추가’ → ‘설치’ 또는 ‘추가’를 눌러요.
  3. 홈 화면에 생긴 학당 아이콘으로 들어오면 끝!
💬 카카오톡에서 링크를 열었다면 오른쪽 위 ⋮ → ‘다른 브라우저로 열기’를 먼저 눌러요.
  1. 꼭 Safari(사파리)로 열어요.
  2. 아래쪽 공유 버튼(□↑)을 눌러요. 안 보이면 주소창 옆 ⋯을 먼저 눌러요.
  3. 목록을 아래로 내려 ‘홈 화면에 추가’를 눌러요.
  4. 오른쪽 위 ‘추가’를 누르면 끝!
💬 카카오톡에서 열었다면 오른쪽 아래 ⋯(또는 나침반) → ‘Safari로 열기’를 먼저 눌러요.
  1. 꼭 Safari(사파리)로 열어요.
  2. 화면 오른쪽 위 공유 버튼(□↑)을 눌러요. 안 보이면 주소창 옆 ⋯을 먼저 눌러요.
  3. ‘홈 화면에 추가’를 눌러요.
  4. 오른쪽 위 ‘추가’를 누르면 끝!
