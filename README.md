# 송현학당 · 우리 반 온라인 학당

운서학당을 학급용으로 바꾼 버전이에요. 같은 Firebase 프로젝트(unseo-hakdang)를 쓰지만,
기록은 `songhyeon/` 칸에 따로 저장돼서 운서학당 친구들 기록과 섞이지 않아요.

## 처음 한 번만 하는 준비
1. **GitHub에 새 저장소 만들기** (예: `songhyeon-hakdang`) → 이 폴더의 파일을 모두 올려요.
2. **Vercel에서 새 프로젝트로 가져오기** → 새 주소가 생겨요. (운서학당 주소와 따로예요)
3. **Firebase 규칙 붙여 넣기**
   Firebase 콘솔 → Realtime Database → 규칙 탭에 `database.rules.json` 내용을 통째로 붙여 넣고 **게시**.
   (이 규칙 안에 운서학당 규칙도 같이 들어 있어서, 운서학당도 그대로 잘 돌아가요.)

## 암호
| 무엇 | 지금 값 | 바꾸는 곳 |
|---|---|---|
| 학생 입장 암호 | `songhyeon17` | `class-config.js`의 pw **그리고** `database.rules.json`의 `songhyeon17` 전부 |
| 선생님 코드 | `songhyeon-teacher` | `database.rules.json`의 `songhyeon-teacher` 전부 |

암호를 바꾸면 규칙을 Firebase 콘솔에 다시 붙여 넣고 게시해 주세요.
선생님 코드는 규칙 파일에만 있어서 학생들은 볼 수 없어요.

## 선생님 화면 켜기
설정 → 연결 → **선생님 모드**에 선생님 코드를 넣고 '켜기' → 설정에 **🧑‍🏫 선생님 화면**이 생겨요.
- 학생별 오늘 출석, 이번 달 출석일, 이번 주·누적 공부 시간, 독후감 수
- 📥 엑셀 표로 내려받기
- 강의실 이름 바꾸기 (예: 국어, 사무관리)
- 기숙사 채팅: 항상 / 정한 시간에만 / 닫기
- 학당 입장 시간: 밤에 문 닫기 (예: 23시에 닫고 6시에 열기)
선생님 모드인 기기는 채팅·입장 제한을 받지 않아요.
